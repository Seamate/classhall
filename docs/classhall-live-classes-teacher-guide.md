# Classhall Live Classes Teacher Guide

Teachers apply through `[classhall_live_teacher_application]`. After admin approval, use `[classhall_live_teacher_dashboard]` to submit group or one-on-one classes.

Use accurate subject, class level, schedule, capacity, price, cancellation policy, and meeting URL information. Meeting links are private and shown only to paid students inside the configured access window.

Submitted classes require admin approval before students can book. Teachers can see class status, seats sold, and basic booking totals in the dashboard.
