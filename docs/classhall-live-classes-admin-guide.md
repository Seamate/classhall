# Classhall Live Classes Admin Guide

1. Activate WooCommerce, Paystack for WooCommerce, and Classhall Live Classes.
2. Visit **Live Classes > Settings** and set commission, currency, capacity, booking buffer, meeting access window, and moderation defaults.
3. Review teacher applications under **Live Classes**.
4. Approve only verified teachers. Approval grants live-class capabilities.
5. Review submitted classes and approve, reject, suspend, cancel, or mark completed.
6. Process refunds through WooCommerce orders.
7. Use payout records only as manual accounting records; Phase 1 does not initiate Paystack transfers.
8. Back up the database before activating on production and before plugin upgrades.
