Classhall Live Classes: Admin Guide

Classhall Live Classes allows approved teachers to create paid online classes for Classhall subjects, while students and parents can discover, book, attend, and review those classes through Classhall.

What the Plugin Handles

  • Teacher applications and verification
  • Live class creation, approval, suspension, completion, and deletion
  • One-on-one and group live classes
  • One-time, weekly, and multiple-days-per-week recurring classes
  • WooCommerce checkout and booking confirmation
  • Student dashboards for joining and reviewing booked classes
  • Teacher dashboards for creating classes, tracking bookings, earnings, and payouts
  • Teacher ratings, verified reviews, and teacher profile pages
  • Reminder emails for students and teachers before class sessions
  • Admin moderation for reviews and teacher payouts

Subject Pages

The plugin automatically adds a live-class block to Sensei subject pages. The block lets users discover live classes for that subject and encourages qualified teachers to apply to teach the subject online.

Only one featured live class is shown directly on a subject page. The plugin chooses the class using teacher quality signals, including rating, review count, completed classes, and upcoming schedule. Students can use the main live classes page to see more available classes for the same subject.

Teacher Application Management

Go to Live Classes in the WordPress admin menu to review teacher applications.

Admin can:

  • Approve, reject, or suspend a teacher application
  • Verify or unverify a teacher separately from approval
  • Review the teacher's profile, qualifications, classes taught, exam specialisations, and bank details

Approving a teacher allows the teacher to access the live-class creation dashboard. Verification is separate and should be used only when Classhall has confirmed that the teacher is trusted, qualified, or otherwise approved for the verified badge.

Live Class Management

Teachers create classes from the teacher dashboard. Admin can then manage submitted classes from the Live Classes admin screen.

Admin can:

  • Approve a submitted class
  • Reject a class that should not be listed
  • Suspend a class that should temporarily stop being available
  • Mark a class as completed
  • Delete a class from active listings while preserving booking and audit records

Approved classes become visible on the relevant live-class pages and can be booked through WooCommerce.

One-Time and Recurring Classes

A class can be created as:

  • One time: a single live session
  • Weekly: one session per week for one month
  • Multiple days per week: more than one session per week for one month

Recurring classes are treated as one bookable class package, not as separate classes. Students book the full recurring package once. The class page shows the schedule summary and the booking price for the package.

Bookings and Checkout

Live class booking uses WooCommerce checkout. When a student or parent books a class and payment is completed, the plugin confirms the booking, reserves the seat, and sends confirmation emails.

The plugin prevents a student from booking two live classes that overlap at the same date and time. If a timing conflict exists, the student must book a different class, usually from another teacher.

Meeting Link Security

Teachers add the private meeting URL when creating the class. The plugin does not display the meeting link publicly.

Booked students see the join option from their live classes dashboard only within the configured meeting access window. This reduces the chance of unbooked users accessing the meeting link.

Reviews and Ratings

After a booked class has been completed, students can confirm that the class held and then review the teacher. A student can update an existing review for the same booking, but the review is not counted as a second review.

Reviews can be moderated by admin before they appear publicly. Teacher ratings shown publicly are based on approved reviews.

Earnings and Payouts

The plugin records teacher earnings from paid live class bookings. Admin can view teacher balances and create payout batches from eligible unpaid earnings.

Teacher bank details submitted through the teacher application form are displayed in the payout admin section to help the admin process manual bank transfers.

Reminder Emails

The plugin can send reminder emails to students and teachers before class sessions. By default, reminders are sent 24 hours and 1 hour before a session.

Go to Live Classes > Settings to manage:

  • Whether reminder emails are enabled
  • Reminder windows in minutes, for example 1440,60
  • Maximum reminder batches per cron run
  • The last reminder cron run status

The reminder system runs through WordPress Cron. It checks only upcoming sessions inside the configured reminder window and uses sent markers so the same reminder is not repeatedly sent.

Important Settings

  • Classhall commission percentage: the platform percentage retained from live class sales.
  • Minimum price: the lowest class price allowed.
  • Maximum class capacity: the highest number of seats a group class can offer.
  • Booking close buffer: how close to start time bookings should close.
  • Meeting link access window: how long before and after a class the meeting link can be shown.
  • Review moderation: whether reviews require admin approval before public display.
  • Class approval required: whether teacher-created classes require admin approval.

Operational Notes

  • Keep WooCommerce active because checkout and order confirmation depend on it.
  • Do not publicly display meeting links on pages, posts, or social media.
  • Review teacher applications carefully before approving and verifying teachers.
  • Use review moderation to protect the quality of teacher profile pages.
  • Process teacher payouts outside Classhall, then mark payout batches accordingly in admin.
